# Театр оперы и балета — мобильное приложение

Мобильное приложение для Государственного театра оперы и балета им. Д.К. Сивцева – Суоруна Омоллоона.

## Технологии
- **Фронтенд:** React + TypeScript + Vite + Capacitor
- **Бэкенд:** Node.js + Express + PostgreSQL
- **Стили:** Tailwind CSS

## Установка и запуск

### Бэкенд
```bash
cd backend
npm install
npm run dev
